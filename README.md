📊 Student Performance Analysis

📌 Project Overview

**Student Performance Analysis** is a Data Science and Data Analytics project that analyzes student academic performance using **Python and MySQL**.

The project explores a student performance dataset to identify patterns and relationships between factors such as study habits, attendance, previous scores, sleep, extracurricular activities, and examination scores.

The project combines **SQL-based database analysis** with **Python-based data analysis** to transform raw student data into meaningful insights.

---

🎯 Objectives

* Analyze student academic performance.
* Explore factors that may influence examination scores.
* Store and query student data using MySQL.
* Perform data analysis using Python.
* Calculate statistical measures and identify patterns.
* Practice SQL queries and Python data analysis techniques.
* Generate meaningful insights from a real-world dataset.

---

* **Python** – Data analysis and processing

📂 Dataset

The dataset contains information about students and factors related to their academic performance.

Important Features

* Student ID
* Hours Studied
* Attendance
* Previous Scores
* Extracurricular Activities
* Sleep Hours
* Sample Question Papers Practiced
* Exam Score

The dataset is used to explore how different factors are associated with students' examination performance.

🐍 Python Analysis

Python is used to perform further data analysis and exploration.

The Python part of the project works with the student dataset and can be used for:

* Loading the dataset
* Exploring the data
* Checking data types and structure
* Identifying missing values
* Performing statistical analysis
* Calculating averages and other measures
* Comparing different variables
* Creating data visualizations
* Identifying patterns in student performance

📈 Analysis Areas

The project explores questions such as:

* What is the average exam score?
* What are the highest and lowest exam scores?
* How many students are present in the dataset?
* How does attendance relate to exam performance?
* Does the number of hours studied relate to exam scores?
* How do previous scores relate to current performance?
* Does participation in extracurricular activities show differences in exam performance?
* Is there a relationship between sleep hours and exam scores?
* Does practicing sample question papers relate to performance?
